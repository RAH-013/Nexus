Es una API REST como la suya: POST, JSON y una clave. La diferencia: ese servidor no es suyo. Puede tardar o fallar.

Esto es todo lo que hay que entender

1

Su API llama a otra API

Igual que su front llama a su API, su API puede llamar a Gemini: es un POST con JSON.

urllib.request.urlopen(req)
2

Tiempo máximo y mensaje claro

Si la IA tarda más de 5 s o falla, su API responde un error que se entiende, en lugar de colgarse o tronar. Y revisa lo que llega.

urlopen(req, timeout=5)
3

La clave fuera del código

La clave de Gemini es como una contraseña: va en una variable de entorno, nunca en el código ni en GitHub.

os.environ.get("GEMINI_API_KEY")

Las 3 ideas, en el código

IA_URL = os.environ.get("EXTERNO_URL", "https://generativelanguage...") IA_CLAVE = os.environ.get("GEMINI_API_KEY", "") def preguntar_a_la_ia(instruccion): cuerpo = {"contents": [{"parts": [{"text": instruccion}]}], ...} req = urllib.request.Request(url, data=json.dumps(cuerpo).encode(), headers={"x-goog-api-key": IA_CLAVE, ...}) try: with urllib.request.urlopen(req, timeout=5) as r: respuesta = json.loads(r.read()) return json.loads(respuesta["candidates"][0][...]["text"]) except TimeoutError: raise HTTPException(504, "La IA tardó demasiado en responder.") except urllib.error.HTTPError as e: raise HTTPException(502, f"La IA no está disponible ({e.code}).") except (ValueError, KeyError, ...): raise HTTPException(502, "La IA respondió algo que no entendemos.") # en su endpoint: nunca confíen en lo que responde la IA ia = preguntar_a_la_ia(INSTRUCCION_IA + datos.titulo) if ia.get("prioridad") not in ("alta", "media", "baja"): raise HTTPException(502, "La IA respondió algo inesperado.")
1Llamar a otra API. Se arma un POST con JSON, como los que ustedes reciben.
2Tiempo máximo y mensaje claro. timeout=5 corta la espera; cada except convierte una falla en un error que se entiende. La última línea revisa lo que llegó.
3La clave fuera del código. La lee de la variable de entorno.
Y EXTERNO_URL permite cambiar a Gemini por el simulador sin tocar el código.
¿Qué código de estado responde su API?

Si la culpa es del otro servidor, no es un 500

200La IA respondió y lo que llegó tiene la forma que pidieron
504La IA no respondió a tiempo (pasaron los 5 s) · Gateway Timeout
502La IA se cayó, rechazó la petición o respondió basura · Bad Gateway
503Su API no tiene configurada la clave: todavía no puede dar ese servicio
¿Por qué no 500? 500 dice “mi código tronó”. 502 y 504 dicen “el problema es del servidor de atrás”. Con eso, el front sabe qué mensaje mostrar y ustedes saben dónde buscar.
