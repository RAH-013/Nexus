Su API le pregunta a una IA

Hoy su proyecto gana un endpoint con IA, y no se cae cuando la IA falla. Elijan su equipo y su lenguaje: el código de abajo se arma para su proyecto.

1 · Su API llama a otra APILa IA es otra API REST: POST, JSON y una clave.
2 · Tiempo máximo y mensaje claroSi la IA tarda o falla, su API responde en 5 s con un 502 o 504 que se entiende.
3 · La clave fuera del códigoEn una variable de entorno. Nunca en GitHub.
Paso 0 · Su equipo y su lenguaje

Es una idea sugerida. Pueden cambiar la ruta, el campo y la instrucción: el código se actualiza solo.

Paso 1 · Su clave de Gemini (5 min, una sola vez)
  1. Entren a aistudio.google.com/apikey con su cuenta de Google y den clic en Create API key. Copien la clave.
  2. En cmd (no PowerShell), guárdenla en una variable de entorno de su usuario: 
    setx GEMINI_API_KEY "pega-aquí-tu-clave"
  3. Cierren ese cmd y abran uno nuevo: setx solo se nota en las ventanas que se abren después.
  4. Pruébenla: python probar_gemini.py. Si les sugiere otro modelo, copien la línea setx GEMINI_MODELO … que imprime.

En Mac o Linux: export GEMINI_API_KEY="tu-clave" en la terminal donde arrancan su API.

La clave es como una contraseña. Nunca en el código, nunca en GitHub, nunca en Classroom ni en un chat. Si se publica, bórrenla en AI Studio y creen otra.

Si algo falla

    

      
Lo que venQué hacer

      
503 Falta configurar la variable de entorno GEMINI_API_KEYAbrieron el cmd antes del setx. Abran uno nuevo y arranquen ahí su API.

      
502 La IA no está disponible (respondió 400 o 403)La clave está mal copiada. Repitan el paso 1 y corran python probar_gemini.py.

      
502 … (respondió 404)Ese modelo no está disponible para su clave. Corran python probar_gemini.py y usen el setx GEMINI_MODELO … que sugiere.

      
502 … (respondió 429)Muchas peticiones seguidas: el plan gratuito tiene límite por minuto. Esperen un minuto.

      
502 … (respondió 503) con la IA realGoogle está saturado en ese momento. Justo para esto es la protección: su API no se cayó. Intenten en un minuto.

      
502 La IA respondió algo inesperadoSu instrucción no pide la forma del JSON entre llaves, o revisan un campo con otro nombre.

      
probar_ia: “¡Su API no le habló al simulador!”Faltó set EXTERNO_URL=http://127.0.0.1:9000 en la ventana de su API, antes de arrancarla.

      
PHP: Call to undefined function curl_init()En php.ini quiten el ; de extension=curl y reinicien.

      
PHP: SSL certificate problemDescarguen cacert.pem de curl.se/docs/caextract.html y en php.ini pongan curl.cainfo = "C:\ruta\cacert.pem".

      
Node: fetch is not definedNecesitan Node 18 o más nuevo (node -v).
